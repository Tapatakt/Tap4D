# Tap4D

Библиотека-рендерер четырёхмерных объектов и сцен (.NET 10, C#, ComputeSharp).

## Концепция

Сцена четырёхмерная. Рендеринг идёт на **трёхмерный виртуальный экран**:

- X и Y виртуального экрана переносятся на реальный экран напрямую;
- координата по ана-ката (W) превращается в цвет: градиент от красного к синему,
  вычисляется попиксельно по W точки пересечения луча с поверхностью;
- если на один реальный пиксель претендуют несколько точек с разной W — они
  чередуются по кадрам;
- зелёный канал зарезервирован под трёхмерные «текстуры» (пока не используется).

## Примитивы сцены

- **Тетраэдры** (4 вершины `Vector4`) — базовые политопы; составные объекты
  собираются из них, как в 3D из треугольников. Бывают видимыми и
  **бесцветными-заслоняющими** (occluders): не отображаются сами, но заслоняют
  другие объекты.
- **Отрезки** — цилиндры с радиусом в мировых единицах (свойство каждого отрезка).
- Сочетание заслоняющих тетраэдров и отрезков даёт «глухо чёрные» объекты
  с видимыми рёбрами (wireframe со скрытыми линиями).

## Рендереры

За общим интерфейсом `IRenderer` — два семейства, каждое в CPU- (эталон) и
GPU- (ComputeSharp/DirectX 12) версиях:

1. **Планарный** (`CpuRenderer`, `GpuRenderer`) — пинхол-проекция f·X/Z, f·Y/Z, f·W/Z.
2. **Рейкастер** (`CpuRaycastRenderer`, `GpuRaycastRenderer`) — честная радиальная
   перспектива: виртуальный экран — сфера направлений, ось ана-ката
   дискретизируется на 64 среза. Даёт W-параллакс: при стрейфе по ана/ката
   красные и синие части объектов расходятся на экране.

Подробности дизайна: `Plan.md` (v1) и `PlanRadial.md` (рейкастер).

## Сборка и запуск

Требования: .NET 10 SDK, Windows. Для GPU-рендереров — DirectX 12
(без него вьювер использует CPU-эталон).

```bash
dotnet build Tap4D.slnx
dotnet test Tap4D.slnx
dotnet run --project Tap4D.Viewer
```

## Управление во вьюере

- Мышь: повороты в XZ (yaw) и YZ (pitch); колёсико — поворот в XW;
  боковые кнопки — наклон в YW; Q/E — крен в XY; Z/X — поворот в ZW.
- Движение: W/S по Z, A/D по X, T/G по W, R/F по Y (объективно).
- M — режим отображения (сплошной / wireframe с заслонкой / только рёбра).
- P — переключение планарный/рейкаст-рендерер.
- +/- — настройка ближней плоскости отсечения.
- Esc — выход.
